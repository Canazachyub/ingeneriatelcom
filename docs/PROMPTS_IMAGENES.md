# Prompts de generación de imágenes — Ingeniería Telcom EIRL

> Para el rediseño Fase 3. Generar y subir a una carpeta `fotos generadas/` en la raíz del proyecto,
> nombradas por código (H1, H2... HERO1, S1...) para saber dónde va cada una.

## Bloque de estilo común — AÑADIR AL FINAL DE CADA PROMPT

```
Professional corporate documentary photography, candid unposed moment, shot on Sony A7 III with 35mm lens at f/2.8, natural available light, realistic skin texture, muted teal-and-amber cinematic color grading, photorealistic, high dynamic range, subtle film grain. No logos, no brand marks, no visible text, no watermarks, subject not looking at camera.
```

## Negative prompt (si tu modelo lo soporta)

```
cartoon, 3d render, illustration, painting, plastic skin, extra fingers, deformed hands, logo, watermark, text, caption, oversaturated colors, studio backdrop, posed stock photo, looking at camera, american faces
```

## Reglas de coherencia

- Personas con rasgos peruanos/andinos (operamos en Tacna, Puno, Arequipa).
- EPP siempre correcto: casco, chaleco naranja/amarillo alta visibilidad, guantes; arnés si hay altura.
- Paisajes del sur del Perú: altiplano (Puno, 3800 m), desierto costero (Tacna), volcanes (Arequipa).
- Nadie mira a cámara. Estilo documental, no stock photo.
- **Aspect ratios**: hélice 3D = 4:3 · hero = 21:9 · secciones/servicios = 16:9 · retratos = 3:4.

## Checklist al generar

- [ ] Generar 2-3 variantes de cada una y elegir la mejor.
- [ ] Verificar manos, arneses y cascos (los modelos suelen fallar ahí).
- [ ] Que NO haya texto legible ni logos inventados en chalecos/cascos/camionetas.
- [ ] Guardar en `fotos generadas/` con el código del prompt (H1.png, HERO1.png...).
- [ ] Mínimo 1600px de ancho (la hélice las muestra grandes); yo las convierto a AVIF/WebP.
